# Maths Tutor App

A timed maths quiz game built with C# and Windows Forms. Players can answer maths questions, track their scores, receive instant feedback, and compete for a place on the leaderboard.

## Features

- Choose a difficulty level and quiz duration.
- Answer timed maths questions.
- Receive feedback on submitted answers.
- Track scores and answer accuracy.
- View and save leaderboard results.
- Restart the quiz and try to improve your score.
- Enter a player name to personalise quiz results.

## How to Play

1. Enter your player name.
2. Choose a difficulty level and time limit.
3. Select **Start Quiz**.
4. Solve the maths questions before time runs out.
5. Enter your answer and select **Submit Answer**.
6. Review your score and accuracy.
7. Restart the quiz or view the leaderboard.

## Built With

- **C#** — application logic and quiz functionality.
- **.NET Windows Forms** — graphical user interface.
- **Microsoft Visual Studio** — development environment.
- **CSV file storage** — saving and retrieving leaderboard results.

## Project Purpose

This project demonstrates practical programming skills, including event-driven programming, user input validation, timer management, score calculation, graphical user interface design, and file handling.
